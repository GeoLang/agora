🤝 Agora

Live multiplayer session service for GeoLang composition documents. One JSON document holds a shared map — layers, annotations, bookmarks, comments — and Agora owns it, orders every edit, and fans the edits out to everyone looking at it.

How It Works

A document is one JSON object. Clients connect over a WebSocket, send operations, and the server assigns every operation a sequence number before fanning it out — the last writer on a key wins. A periodic checkpoint of the merged document is stored beside the op log, so a late joiner loads the checkpoint and replays the tail instead of the whole history. Agora runs as a single instance and is the only writer to its database.

Features

📄 Documents & Members

  • UUID-keyed documents, creator becomes first editor
  • Per-document members with view or edit role
  • Last-editor protection: a document cannot lose its only editor
  • Non-members get "no such document", so ids cannot be probed

🔗 Share Links

  • Tokened links granting view or edit
  • Only the token hash is stored server-side
  • Revocable at any time
  • Visitors get short-lived session tokens, never platform credentials

💬 Comments & Notifications

  • Comments live in the document like any other keyed state
  • @-mentions create notifications for the mentioned user
  • Notification list and mark-read endpoints

📎 Attachments

  • Binary blobs referenced from the document
  • Fetched by token, so image overlays work in a browser

🔌 WebSocket Protocol

  • Ops, batched ops, and presence messages
  • Presence is relayed, never persisted
  • Frame and batch size limits refuse oversized input
  • Bearer token offered as a subprotocol, echoed never

🔐 Auth

  • Platform HS256 JWTs, same secret as the other services
  • Scopes: agora:read for GET, agora:write for the rest
  • Authorization decided by the members table per document
  • Fail-closed: no secret, no start

REST API

MethodEndpointDescription
POST / GET/documentsCreate a document / list the caller's documents
GET/documents/{id}Fetch a document (members only)
PUT / DELETE/documents/{id}/members/{user_id}Set or remove a member and role
POST/documents/{id}/linksCreate a share link
GET / DELETE/links/{token}Resolve or revoke a share link
POST/documents/{id}/attachmentsAdd an attachment
GET/attachments/{token}Fetch an attachment blob
GET/notificationsList the caller's notifications
POST/notifications/readMark notifications read
GET/wsWebSocket upgrade for a document session
GET/healthHealth check

In the platform Compose stack, nginx serves all of this under /agora/.

Quick Start

# Build and run (migrations run at startup)
git clone https://github.com/GeoLang/agora.git
cd agora
PLATFORM_JWT_SECRET=... DATABASE_URL=postgres://... cargo run -p agora-server
VariableRequiredMeaning
PLATFORM_JWT_SECRETyesShared HS256 secret, 32 bytes or more, the same one the other platform services validate
DATABASE_URLyesPostgres connection string, carries the TLS mode
PORTnoListen port, 3000 by default
